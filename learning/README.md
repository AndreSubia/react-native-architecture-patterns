# 📚 Learning Section / Sección de Aprendizaje

This folder contains foundational concepts that support the development of scalable, maintainable React Native apps. It includes hands-on examples of TypeScript, Functional Programming, Object-Oriented Programming (OOP), SOLID Principles, and Clean Architecture.

Esta carpeta contiene conceptos fundamentales que apoyan el desarrollo de aplicaciones React Native escalables y mantenibles. Incluye ejemplos prácticos de TypeScript, Programación Funcional, Programación Orientada a Objetos (POO), Principios SOLID y Arquitectura Limpia.

Explora los fundamentos de TypeScript: tipos, interfaces y alias de tipos — todo clave para escribir código más seguro y predecible.
